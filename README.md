# Daily Islamic Routine

This package contains the app source and a GitHub Actions workflow for building an Android APK.

## Phone-only build
1. Upload this project to a GitHub repository.
2. Open the repository's Actions tab.
3. Choose **Build Android APK**.
4. Tap **Run workflow**.
5. After the workflow finishes, open the successful run and download the artifact named `daily-islamic-routine-apk`.
6. Extract the downloaded artifact and install `app-release.apk`.

No Android Studio is required on your phone for this cloud build route.

## App features
- 5 daily prayers
- Quran recitation
- Study routine
- Zikr
- Progress indicator
- Add/delete routines
- Local persistence
